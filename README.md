# CO2203-Project-Restart

## Build and run on Windows

Requirements: Git, a C++17 compiler, and GNU Make.

From the project root:

```powershell
mingw32-make
.\mainApp.exe
```

## Project folders

- include/ — C++ header files.
- src/ — C++ source files.
- data/ — Saved application data.
- docs/ — Project documentation.
